# Tests for custom modules

This directory contains tests for code that we develop as custom
modules/extensions.

## cpp_switch.lua

Test invocation:

```bash
nvim --headless -l tests/test_cpp_switch.lua
```

## follow_mode.lua

Test invocation:

```bash
nvim --headless -l tests/test_follow_mode.lua
```

## markdown_checkbox.lua

Test invocation:

```bash
nvim --headless -l tests/test_markdown_checkbox.lua
```
